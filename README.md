## How to get them

- In the VacuumTube app.
  - Navigate to the Settings "cog" icon on the bottom left corner.
  - Scroll to the "Custom CSS/Userstyles" tab, and enable it.
  - Open the userstyles folder with the button, else use paths below, OS-wise.
  - Put the CSS files directly into there, not in any subfolders.

### MacOS

```shell
~/Library/Application Support/VacuumTube/userstyles/
```

### Linux

#### Flatpak

```shell
~/.var/app/rocks.shy.VacuumTube/config/VacuumTube/userstyles/`
```

#### Native

```shell
~/.config/VacuumTube/userstyles/
```
